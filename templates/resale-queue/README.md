# Resale queue layout (any sync provider)

Sync or copy the parent `Resale/` folder between phone and PC (Google Drive, iCloud, Dropbox, OneDrive, NAS, etc.). Each item lives under `queue/<item-id>/`.

```text
Resale/
  .resale-config.json          # optional local defaults
  queue-index.json             # generated by scripts/resale_queue.py index
  queue-index.csv              # dashboard for any spreadsheet app
  queue/
    2026-10-16-ikea-chair/
      inbox/                   # phone uploads land here
      photos/
        original/              # archived camera files after processing
        post/                  # sanitized JPEGs for posting (sync-safe)
      listing.md               # full agent handoff
      meta.json                # status + prices + photo metadata_status
```

See [persistence.md](../../skills/resale-ops/references/persistence.md). Google-specific steps: [drive-sheets-queue.md](../../skills/resale-ops/references/drive-sheets-queue.md).
