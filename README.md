# Помощник объявлений на маркетплейсах

Переносимый Agent Skill и плагин: фотографии → распознавание → проверяемые аналоги → две ценовые стратегии → текст → черновики на Авито, Юле и других поддержанных площадках.

**Ничего не публикует без отдельного явного подтверждения итогового объявления.** Не обходит CAPTCHA, ограничения и авторизацию. Не включает платные услуги автоматически.

Версия 0.2.0. Неофициальный проект, не связан с Авито, Юлой или другими площадками. Это инструкции для ИИ-агента, а не самостоятельное приложение. Нужны Codex, Claude Code или Cursor с распознаванием изображений; для актуальной оценки — интернет, для заполнения — настроенный браузерный инструмент.

## Начать без технических знаний

1. Скачайте и распакуйте проект. Откройте эту папку в своём ИИ-приложении.
2. Вставьте: «Установи локально skill из `skills/resale-ops` для моего приложения. Не подключай браузер и ничего не публикуй. Следуй `docs/INSTALL.md`».
3. Начните новый чат и приложите фото одной вещи: общий вид, маркировка, комплект, дефекты.
4. Напишите: «Используй resale-ops. Подготовь продажу этой вещи на Авито и Юле. Город: … Состояние и дефекты: … Комплект: … Срок: … Самовывоз/доставка: … Заполни черновики, но не публикуй».
5. Если браузер не подключён, помощник подготовит тексты и объяснит настройку. Войдите на площадки самостоятельно. Проверьте загруженные фото, цены и тексты; финальный клик можно всегда сделать вручную.

Не вводите пароли и SMS-коды в чат. Не добавляйте личные фотографии, адреса и выгрузки аккаунта в публичный репозиторий.

- [Установка для трёх приложений](docs/INSTALL.md).
- [Совместимость, registries и источники](docs/COMPATIBILITY.md), проверено 15 октября 2026.

- [Проверки и ограничения](docs/TESTING.md).
- [Подготовка публичного релиза](docs/RELEASE.md).

Общее ядро находится в `skills/resale-ops/`, а правила различий площадок — в `references/platforms.md`. Корневой `plugin.json` использует Agent Plugins; `.claude-plugin/plugin.json` — оболочка Claude Code для того же ядра. Не устанавливайте одновременно skill и плагин в одном приложении: возможны дубли.

Установка skill не устанавливает браузерный MCP. Плагин тоже не запускает браузер автоматически. Переносимость формата не гарантирует одинаковые возможности инструментов во всех приложениях.
