# Resale Ops — помощник продажи б/у вещей

<img src="assets/resale-ops.png" alt="Resale Ops" width="112" height="112">

By **Max Kayander** · MIT · Codex / Claude Code / Cursor

Переносимый Agent Skill и плагин: фотографии → распознавание → оценка по подтверждённым аналогам → две ценовые стратегии → тексты и поля для ручного размещения на Авито, Юле и похожих площадках.

**Для Авито и Юлы агент готовит материалы без входа в ваш аккаунт.** Допустимы обычный поиск в интернете и анонимный просмотр публичных страниц (в т.ч. для ориентировочной цены, характеристик и справочных фото товара). Заполнение формы, загрузку ваших фото и публикацию выполняет человек. Автоматизация от имени аккаунта возможна только через отдельно проверенный адаптер; таких адаптеров пока нет. Нулевой риск блокировки не обещается.

Неофициальный проект, не связан с Авито, Юлой или другими площадками. Это инструкции для ИИ-агента, а не самостоятельное приложение и не техническая песочница. Нужны Codex, Claude Code или Cursor с распознаванием изображений и доступом к поиску в интернете. Ориентировочную цену агент может собрать из открытых источников; для более строгой оценки передайте сведения из объявлений, которые вы проверили вручную, с прямыми ссылками и временем проверки. Браузерный MCP и вход в аккаунт маркетплейса не нужны.

## Установка одной командой

Через CLI [skills.sh](https://skills.sh/docs) из папки своего проекта:

```sh
npx skills add mkayander/resale-ops --skill resale-ops
```

Выберите своё приложение и область установки в диалоге. Нужен Node.js с `npx`;
Python и Google API для установки самого skill не нужны. Публикация в каталоге
OpenAI и верификация OpenAI для этого способа не требуются. skills.sh учитывает
установки для обнаружения и рейтинга; наличие рейтинга не заявляется.

В Claude Code можно вместо отдельного skill установить плагин из нашего
GitHub-каталога сообщества:

```sh
claude plugin marketplace add mkayander/resale-ops
claude plugin install resale-ops@mkayander-plugins --scope project
```

После перезапуска сессии: `/resale-ops:resale-ops`. Это наш собственный каталог,
а не одобрение Anthropic. Выберите один способ установки, чтобы избежать дублей.
Подробности, локальная установка без сети и обновления — в [инструкции](docs/INSTALL.md).

## Начать без технических знаний

1. Скачайте и распакуйте проект. Откройте эту папку в своём ИИ-приложении.
2. Вставьте: «Установи локально skill из `skills/resale-ops` для моего приложения. Не подключай браузер и ничего не публикуй. Следуй `docs/INSTALL.md`».
3. Начните новый чат и приложите фото одной вещи: общий вид, маркировка, комплект, дефекты.
4. Напишите: «Используй resale-ops. Подготовь тексты и поля для Авито и Юлы. Город: … Состояние и дефекты: … Комплект: … Срок: … Самовывоз/доставка: … Есть ли уже объявление этой вещи: … Я размещу вручную».
5. При необходимости уточните оценку: проверьте несколько аналогов и передайте ссылки, цены, состояние и время проверки. Перед размещением проверьте текст, справочные фото (если используете), отсутствие дубля и личных данных на фото, включая GPS-метаданные. Заполните форму и опубликуйте самостоятельно.

Не вводите пароли и SMS-коды в чат. Не добавляйте личные фотографии, адреса и выгрузки аккаунта в публичный репозиторий.

## Очередь телефон → ПК (любое облако)

Синхронизируйте папку `Resale/` через Google Drive, iCloud, Dropbox, OneDrive или другое хранилище: фото в `inbox/`, агент готовит `listing.md`, скрипт сжимает и очищает метаданные в `photos/post/`. Индекс — `queue-index.csv` (Excel, Notion и т.д.) или опционально Google Sheets.

- [Очередь и хранилище](docs/DRIVE-SHEETS-QUEUE.md)
- [Постоянные ID (облако / project memory)](docs/PERSISTENT-CONFIG.md) — без локального диска
- Команды: `python scripts/resale_queue.py` (`init`, `prepare-photos`, `index`, `sheet-push`)
- Зависимости: `python -m pip install -r requirements-queue.txt`

## Для разработчика

Установщик требует Python 3.10+ без дополнительных зависимостей. Для проверки пакета создайте отдельное окружение и установите зависимости разработчика:

```sh
python -m pip install -r requirements-dev.txt
python scripts/check_package.py
python -m unittest discover -s tests -v
```
