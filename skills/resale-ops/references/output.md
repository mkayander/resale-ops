# Карточка результата

- Предмет и уверенность распознавания.
- Подтверждено фото / владельцем / ещё неизвестно.
- Состояние, дефекты, комплект, город, передача.
- Аналоги: для каждого прямая ссылка, время проверки, цена, характеристики, доступность, включение и причина. Можно списком; не выдумывай карточки для заполнения шаблона.
- Выборка и расчёт: n, медиана, диапазон, исключения, поправки, ограничения.
- При MCP-исследовании: источник/версия сервера, предупреждения, частичная доступность, кэш/его возраст, проверка прямой карточки. Цена нового товара показывается отдельно от б/у выборки.
- Рыночный ориентир; цена быстрой продажи; выбранная цена объявления.
- Заголовок; описание; категория и характеристики.
- Фото: выбранные имена и порядок; результат загрузки.
- Браузер: аккаунт подтверждён без персональных данных, прочитанные поля, ошибки, сохранение подтверждено/нет, ссылка на черновик если интерфейс её предоставляет.
- Статус: prepared/form_filled/draft_saved/blocked/submitted/published.
- Следующий шаг и явная остановка перед публикацией.

Не включай точный адрес/телефон, cookies, токены или содержимое других вкладок. Храни личные рабочие файлы вне публичного репозитория.
