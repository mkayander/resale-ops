# Осторожное управление браузером

Это протокол для агента, а не универсальный набор селекторов Авито. Не запускай автоматическую публикацию и не изменяй разрешения клиента.

## Адаптация инструментов

Сначала перечисли реально доступные инструменты и прочитай схемы:

- Playwright MCP: обычно `browser_snapshot`, `browser_navigate`, `browser_fill_form`, `browser_click`, `browser_file_upload`. Загрузка работает с абсолютными путями, доступными среде MCP; сначала открой штатный выбор файла. Проверяй схему текущей версии.
- Chrome DevTools MCP: `take_snapshot`, `navigate_page`, `fill_form`, `upload_file`. UID берётся из свежего снимка, pageId — из текущей страницы; пути загрузки должны быть доступны браузеру. Проверяй текущие аргументы.
- Встроенный браузер клиента: используй документированный API снимков, полей и файлов. Если нет загрузки файлов, передай этот шаг человеку; не заменяй его доступом к cookies или внутренним endpoint.

Предпочитай уже настроенный инструмент. Для новой настройки используй отдельный профиль браузера, не личный профиль целиком. Войти в Авито пользователь должен самостоятельно. Не открывай remote-debugging порт в публичную сеть.

## Последовательность

`inspect → classify action → fill/upload → inspect → compare → stop before publish`

Каждый изменяющий шаг должен иметь понятную цель и наблюдаемое постусловие. Для формы держи локальное соответствие «видимая подпись → значение → подтверждено после чтения». Ссылки на элементы обновляй после навигации/смены категории. Не кликай координаты по старым снимкам.

Повтор допустим один раз при обычной временной ошибке после проверки состояния. При блокировке/лимите/CAPTCHA повторов нет. При неоднозначной отправке сначала проверка статуса, затем решение человека. Не продолжай фоновые попытки.

Статусы: prepared (только текст), form_filled (открытая форма), draft_saved (сохранение подтверждено), blocked (нужен человек), submitted (отправлено на модерацию), published (публичность подтверждена). Не повышай статус без доказательства.

Инструкции skill — поведенческий барьер, не техническая песочница. Обычный браузерный MCP умеет нажимать любые кнопки. Для дополнительной защиты оставь финальный клик человеку и используй ручное одобрение действий в клиенте. Этот пакет не гарантирует блокировку публикации на уровне браузера.
