# Браузер

Используйте уже доступный инструмент клиента, если он поддерживает чтение формы, заполнение и загрузку локальных файлов. Настройка MCP отличается от установки skill.

## Playwright MCP

Первичный источник: [microsoft/playwright-mcp](https://github.com/microsoft/playwright-mcp). Есть снимки доступности, заполнение форм и загрузка файлов. Нужен Node.js; системные требования сверяйте с README установленной версии.

Пример фрагмента конфигурации для клиента, принимающего `mcpServers` (например Claude Code/Cursor):

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["@playwright/mcp@latest"]
    }
  }
}
```

Это пример, а не автоматически установленный файл. `latest` удобен для первой настройки; после проверки закрепите фактически проверенную версию. На некоторых Windows-конфигурациях требуется `npx.cmd`. Не копируйте JSON в TOML-конфигурацию Codex: добавьте сервер штатным интерфейсом MCP вашего клиента с теми же command/args.

Запускайте видимый браузер в отдельном профиле. Войдите в Авито вручную. Проверьте инструмент загрузки на тестовой форме прежде, чем использовать аккаунт. Локальные файлы должны быть доступны машине MCP; путь на ноутбуке не появляется автоматически на удалённом сервере.

## Chrome DevTools MCP

Альтернатива: [официальный репозиторий](https://github.com/ChromeDevTools/chrome-devtools-mcp) и [tool reference](https://github.com/ChromeDevTools/chrome-devtools-mcp/blob/main/docs/tool-reference.md). Поддерживает снимки, поля и `upload_file`; пути файлов должны быть доступны браузеру. Настройку подключения к Chrome выполняйте по README текущей версии. Не включайте ненужный сбор диагностик; проверьте настройки телеметрии выбранного сервера.

## Пределы

Ни один MCP не гарантирует доступность Авито или поддержку конкретного виджета загрузки. Уважаются ограничения площадки: при CAPTCHA/запрете доступа — ручной шаг, без смены IP и обходов. Плагин не хранит логин/пароль и не содержит скрытого API Авито.

Без браузера работают анализ фото и текст. Без живого доступа текущие цены не подтверждаются. Без upload-инструмента фото загружает пользователь. Финальный клик публикации рекомендуется оставлять человеку даже при установленном MCP.
