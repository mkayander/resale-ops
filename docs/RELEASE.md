# Публичный релиз

Пакет подготовлен для GitHub, но нигде не опубликован.

Перед публикацией владелец выбирает имя репозитория и подтверждает публичный доступ и лицензию MIT. Проверьте отсутствие личных фото, контактов, точных адресов, сессий браузера и реальных черновиков. Не добавляйте рабочий каталог продажи в репозиторий.

Выполните локальные проверки и ручную приёмку из TESTING.md. После испытаний закрепите проверенную версию MCP в своей конфигурации; базовый пакет не навязывает сервер.

Создайте публичный GitHub-репозиторий только после явного подтверждения владельца; загрузите именно эту папку. Добавьте URL repository/homepage в manifest, замените OWNER/REPO в INSTALL.md, создайте tag и ZIP релиза. Не заявляйте совместимость клиента как проверенную до его испытания.

После публикации можно отдельно распространять через skills.sh CLI, marketplace Claude Code и рассмотрение каталога OpenAI/Cursor. Публичный GitHub сам по себе не означает принятие магазином. Условия подачи проверяйте заново по ссылкам в COMPATIBILITY.md. Этот проект не регистрирует каталог, не отправляет заявки и не выполняет push.
