# Публичный релиз

Исходники опубликованы в [mkayander/resale-ops](https://github.com/mkayander/resale-ops) под MIT. Регистрация в магазинах плагинов выполняется отдельно; принятие в магазин не заявляется.

Перед каждым релизом проверьте отсутствие личных фото, контактов, точных адресов, сессий браузера и реальных черновиков. Не добавляйте рабочий каталог продажи в репозиторий. Проверьте состав отслеживаемых файлов: `.gitignore` не исключает уже отслеживаемые данные.

Обновите версию одновременно в `plugin.json`, `.claude-plugin/plugin.json` и README. Выполните проверки из [TESTING.md](TESTING.md). Результаты ручной приёмки фиксируйте отдельно от автоматических тестов; не объявляйте невыполненные проверки успешными. Для MCP действует [ограничение проверенной ревизии](RU-MARKETPLACE-MCP.md), пока не выполнены критерии возобновления.

После коммита подготовьте ZIP из отслеживаемых файлов, например для 0.3.1:

```sh
git archive --format=zip --prefix=resale-ops/ --output=../resale-ops-0.3.1.zip HEAD
```

Проверьте распакованный архив теми же тестами. В нём не должно быть `.git`, виртуальных окружений и кэшей. Создание тега и GitHub Release — отдельные действия владельца; сам архив их не создаёт. Не заявляйте совместимость клиента как проверенную до его испытания.

Публичный репозиторий уже доступен для установки через skills.sh CLI. Для marketplace Claude Code и каталогов OpenAI/Cursor следуйте актуальным процедурам из [COMPATIBILITY.md](COMPATIBILITY.md). Скрипты этого проекта не регистрируют каталоги, не отправляют заявки и не выполняют push.
