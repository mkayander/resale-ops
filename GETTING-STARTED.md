# Первый запуск Resale Ops

Подготовьте объявление о продаже одной вещи: фото → уточнения → оценка → текст.
Вы проверяете результат и размещаете объявление самостоятельно.

## Используете ChatGPT Project?

Начните с [настройки проекта ChatGPT](docs/CHATGPT-PROJECT.md): загрузите полный
workflow, вставьте готовые инструкции с ID Drive/Sheets и проверьте подключения.
Для этого пути локальная установка через `npx` не требуется. Дальнейшие шаги
установки ниже относятся к Codex, Claude Code и Cursor.

## 1. Выберите приложение

Подойдёт **Codex**, **Claude Code** или **Cursor** с поддержкой изображений.
Для актуальных цен нужен поиск в интернете. Установленная подписка или доступ
к модели в вашем приложении настраиваются отдельно.

По умолчанию используем **Google Drive для фото и черновиков** и **Google Sheets
для очереди вещей**. Нужны Google-аккаунт и подключение этих сервисов к агенту.
Python на вашем ПК, синхронизация Drive for desktop и вход агента в Авито/Юлу
не нужны для настройки облачной очереди. Это инструкция для установки в выбранное
приложение; загрузка файла в обычный чат сама по себе не устанавливает skill.

## 2. Подготовьте рабочее пространство

Откройте отдельный проект в своём ИИ-приложении. Если приложение требует папку,
создайте пустую `My Resale` и откройте её. Она нужна для установки skill;
фотографии, черновики и очередь по умолчанию будут в Google Drive и Google Sheets.

Откройте терминал в этом проекте: встроенный терминал приложения, PowerShell
в Windows или Terminal в macOS/Linux.

## 3. Установите skill

Нужны [Node.js LTS](https://nodejs.org/en/download) с командой `npx` и
[Git](https://git-scm.com/downloads). Если они уже установлены, пропустите
установку. После установки откройте терминал заново.

Скопируйте **только одну** команду для своего приложения:

| Приложение | Команда в терминале |
| --- | --- |
| Codex | `npx skills add mkayander/resale-ops --skill resale-ops --agent codex` |
| Claude Code | `npx skills add mkayander/resale-ops --skill resale-ops --agent claude-code` |
| Cursor | `npx skills add mkayander/resale-ops --skill resale-ops --agent cursor` |

Если `npx` предложит скачать пакет `skills`, подтвердите установку этого пакета.
Если появится выбор области установки, выберите **Project / текущий проект**.
Дождитесь сообщения об успешной установке `resale-ops`.

Эти команды скачивают skill из публичного GitHub-репозитория. Не устанавливайте
его повторно другим способом в то же приложение. Если предпочитаете установку
без Node.js или уже используете Claude-плагин, смотрите [другие способы](docs/INSTALL.md).

## 4. Подключите Google Drive и Google Sheets

В настройках подключений своего ИИ-приложения подключите интеграцию, которая
даёт агенту доступ к Google Drive **и** Google Sheets. Названия и способ подключения
зависят от приложения. Войдите в Google через его окно авторизации; пароль и
коды входа в чат не отправляйте. Сам Resale Ops не устанавливает эти подключения.

Нужен доступ к чтению фото, созданию папок, чтению и записи файлов Drive,
а также чтению и изменению строк Sheets. Поиск по Drive без записи не подходит
для ведения очереди. Не делайте папку или таблицу общедоступными.

Откройте новый чат в том же проекте и отправьте:

```text
Используй resale-ops. По умолчанию работаем через Google Drive + Google Sheets.
Проверь доступные инструменты: чтение фото, создание папок, чтение и запись файлов
в Drive, чтение и изменение строк Sheets. Пока ничего не создавай.
Если какой-то возможности нет, перечисли её и объясни, какое подключение нужно.
Не сообщай об успешном подключении без фактической проверки.
```

Если необходимых инструментов нет, сначала настройте подключение. Подготовить
текст в чате можно и без него, но облачная очередь ещё не будет настроена.
[Подробнее о требованиях к подключениям](docs/DRIVE-SHEETS-QUEUE.md).

## 5. Создайте облачную очередь один раз

Отправьте агенту:

```text
Настрой Resale Ops в моём Google Drive и Google Sheets.
Сначала найди существующие Resale и таблицу очереди; если найдено несколько,
уточни выбор. Используй мои сохранённые настройки, если они есть.
Если очереди ещё нет, создай папку Resale с подпапкой queue и отдельную Google
таблицу Resale Queue с вкладкой Queue. Не изменяй другие папки и таблицы.
Создай нужные заголовки очереди по инструкции skill.
Сохрани реальные ID и ссылки в Resale/.resale-locations.json; покажи мне
блок настроек, который я добавлю в инструкции проекта для следующих чатов.
Город по умолчанию: [ваш город]. Площадки: Авито и Юла.
После настройки покажи ссылки на папку, queue и таблицу и подтверди результат
по ответам инструментов. Если запись недоступна, ничего не выдумывай.
```

Откройте выданные ссылки и проверьте папку и таблицу. Скопируйте блок настроек
в инструкции своего проекта: в следующих чатах агент сможет загрузить те же ID.
[Как сохранить настройки](docs/PERSISTENT-CONFIG.md). ID не являются паролями,
но относятся к вашему рабочему пространству; не коммитьте их в публичный репозиторий.

Для первой вещи попросите:

```text
Создай в моей облачной очереди одну новую вещь: [краткое название].
Создай папку с уникальным ID, inbox, photos/post, listing.md и meta.json.
Добавь строку в Queue со статусом draft и ссылкой на папку вещи.
Покажи ссылку на inbox для загрузки фотографий.
```

В Google Drive на телефоне или ПК откройте `inbox` по ссылке и загрузите фото
**одной вещи**: общий вид, маркировку модели, комплект и дефекты. Проверьте,
что на снимках нет адресов, документов, лиц и других личных данных.

Теперь отправьте запрос, заменив поля в квадратных скобках:

```text
Используй resale-ops. Подготовь объявление для Авито и Юлы для вещи [ID или ссылка
на папку]. Фотографии уже в её inbox в Google Drive.

Город: [ваш город, без точного адреса]
Вещь и модель, если известны: [что продаёте]
Состояние и проверка работоспособности: [что проверено, что неизвестно]
Дефекты: [все известные дефекты]
Комплект: [что входит и чего нет]
Срок продажи: [быстро / готов подождать / конкретный срок]
Передача: [самовывоз / доставка / оба варианта]
Есть ли уже объявление этой вещи: [нет / есть на ... / не знаю]

Сначала задай важные уточняющие вопросы. Затем предложи цену для быстрой
продажи и обычную стартовую цену с источниками и оговорками. Подготовь заголовок,
описание, поля и порядок фото отдельно для каждой площадки.
Сохрани результат в listing.md и meta.json, обнови эту строку Queue по ID.
Подготовь очищенные от метаданных копии фото в photos/post, если инструменты
позволяют это реально выполнить и проверить. До этого не ставь статус ready.
Я проверю результат и опубликую вручную.
```

Агенту может понадобиться временное рабочее пространство для обработки фото.
Это не требует постоянной синхронизируемой папки на вашем ПК. Если обработка
или загрузка копий недоступна, агент должен сообщить об этом, оставить вещь
неготовой к размещению и дать ручной следующий шаг. Не передавайте в чат пароли,
коды входа, cookies или ключи сервисных аккаунтов.

## 6. Ответьте на уточнения и выберите цену

Агент должен отделить видимые факты от предположений, уточнить модель и состояние,
а затем предложить ценовые варианты. Это оценка по доступным **ценам предложений**,
а не обещание продажи за определённую сумму или срок.

Если веб-поиск недоступен, попросите поисковые запросы и проверьте похожие
объявления самостоятельно. Передайте ссылки, цены, состояние и время проверки.
Без источников не считайте оценку подтверждённой рынком.

Выберите стартовую цену и при необходимости попросите исправить текст.

## 7. Проверьте и разместите объявление

Перед переносом на площадку проверьте:

- точную модель, состояние, дефекты и комплект;
- выбранную цену, город и условия передачи;
- что все характеристики подтверждены вами или источниками;
- порядок фото, права на изображения и отсутствие личных данных;
- EXIF/GPS: удаление метаданных должно быть выполнено и проверено отдельно;
- что на этой площадке уже нет объявления или черновика той же вещи.

Откройте `listing.md` и очищенные копии в `photos/post` по ссылке из строки Queue.
Скопируйте текст и поля в форму Авито/Юлы, загрузите выбранные фото, проверьте
предпросмотр и опубликуйте самостоятельно. Resale Ops не входит в ваш аккаунт,
не заполняет формы и не публикует объявления. Успешный первый результат —
проверенный пакет текста, цены, полей и фото в Drive и актуальная строка Queue
для ручного размещения. После публикации сообщите агенту площадку и ссылку:
он обновит строку до `posted` как ваше подтверждение, а не как собственную публикацию.

## Если что-то не получилось

| Проблема | Что сделать |
| --- | --- |
| `npx` или `git` не найдены | Установите Node.js LTS или Git по ссылкам выше и откройте терминал заново. |
| Skill не найден | Откройте папку, где выполнялась установка, и начните новую сессию. Проверьте наличие `SKILL.md` по путям ниже. |
| Команда `/resale-ops` не появляется | Используйте текстовый запрос из шага 4 и проверьте инструкции установки для своего приложения. |
| Уже установлен Claude-плагин | Используйте `/resale-ops:resale-ops`; не добавляйте второй standalone skill. |
| Агент не видит фотографии | Проверьте правильность inbox и доступ подключения к этой папке и изображениям. |
| Агент видит Drive, но не может сохранять файлы или менять Sheets | Подключите инструменты с нужными возможностями записи; один поиск не ведёт очередь. |
| В новом чате запрашиваются ссылки | Добавьте реальные ID из настройки в инструкции проекта; проверьте доступ к облачному конфигу. |
| Агент не может проверить цены | Передайте вручную проверенные аналоги или попросите черновик с явно предварительной оценкой. |

Пути от папки вашего проекта: Codex — `.agents/skills/resale-ops/SKILL.md`,
Claude Code — `.claude/skills/resale-ops/SKILL.md`, Cursor —
`.cursor/skills/resale-ops/SKILL.md`. Установщик может использовать общую папку
`.agents/skills` и ссылки из каталога приложения. Не перемещайте только
`SKILL.md`: ему нужна вся папка `references`.

## Дополнительно: локальная работа и обновления

Google Drive + Google Sheets — основной сценарий. Если вы явно предпочитаете
локальные файлы, другие облака или синхронизацию на ПК, смотрите
[дополнительные варианты](docs/DRIVE-SHEETS-QUEUE.md). Они не нужны для основного
облачного сценария.

Обновления и другие способы установки описаны в [полной инструкции](docs/INSTALL.md).
[Исходники и сообщения о проблемах](https://github.com/mkayander/resale-ops).
