# Первый запуск Resale Ops в вебном ChatGPT

Одна инструкция: настройка ChatGPT Project → Google Drive + Google Sheets →
фото вещи → оценка и текст → ручное размещение на Авито и Юле.
**Источник skill — GitHub:** [исходный SKILL.md](https://github.com/mkayander/resale-ops/blob/main/skills/resale-ops/SKILL.md).
Для ChatGPT Project используйте прямое чтение Markdown из GitHub, как указано
в шаблоне ниже. Страница в каталоге skills.sh не требуется; её индексация
пока не подтверждена.

Все шаблоны для копирования находятся прямо здесь. Для ChatGPT Project не нужны
локальная установка skill, терминал, Node.js или Python на вашем ПК.

## Самый быстрый способ: дайте агенту инструкцию настройки

Скопируйте эту raw-ссылку в новый чат внутри ChatGPT Project и попросите агента
выполнить её:

```text
https://raw.githubusercontent.com/mkayander/resale-ops/main/docs/AGENT-SETUP.md
Прочитай эту инструкцию и настрой Resale Ops пошагово. Проверь, что этот чат
находится в отдельном ChatGPT Project. Если проекта нет, попроси меня создать его.
Проверь Google Drive и Google Sheets; если подключения нет, попроси меня подключить.
Найди или создай в Google Drive папку Resale, queue, таблицу Queue и приватный файл
.resale-locations.json внутри Resale.
В начале каждого нового чата прочитай текущий skill и проверь, изменился ли GitHub-
источник после сохранённой версии. Если изменился, кратко покажи важные изменения
и предложи обновить инструкции проекта; не заменяй закреплённую копию молча.
В долгом чате повторяй такую проверку после длительной паузы, перед новой настройкой
или интеграцией и при вопросах об обновлении; обычную работу с вещью не прерывай.
Если инструкции Resale Ops ещё нет в настройках проекта, выдай готовый блок для
копирования с фактическими ссылками и ID. Не выдумывай результаты, всё проверяй чтением.
После настройки покажи ссылки и попроси загрузить фотографии первой вещи.
```

Это предпочтительный путь: агент сам определит, что уже настроено, и запросит
только недостающие действия. Если проект, подключения или создание ресурсов
недоступны в текущем приложении, он должен сообщить об этом и продолжить с тем,
что можно подготовить без записи.

## 1. Создайте ChatGPT Project

Создайте отдельный проект для продажи вещей. Дальнейшие чаты начинайте внутри
этого проекта, чтобы они использовали общие инструкции и ID облачной очереди.
Для фото нужна модель с поддержкой изображений, для актуальных цен — веб-поиск.
Доступ к модели и Google-сервисам настраивается отдельно в вашем приложении.

Codex, Claude Code и Cursor поддерживаются как дополнительные варианты; их установка
описана в конце **этого же файла**. Для основного вебного ChatGPT-сценария локальная
установка skill не нужна.

## 2. Подключите Google Drive и Google Sheets

В настройках подключений ChatGPT подключите Google-сервисы через окно авторизации.
Нужны реальные возможности чтения фото, создания папок, чтения/записи файлов
Drive и чтения/изменения строк Sheets. Сам Resale Ops не подключает сервисы.
Один поиск по Drive не означает наличие записи. ID не предоставляют доступ.
Названия настроек и доступные действия зависят от аккаунта и приложения.

Для обработки фото агенту может понадобиться временное рабочее пространство;
постоянная синхронизация Drive с вашим ПК не требуется.

## 3. Вставьте готовые инструкции проекта

Скопируйте **весь блок ниже** в инструкции ChatGPT Project. Если очередь уже есть,
замените REPLACE ID соответствующих папок, таблицы и вашим городом. Если очереди ещё нет, укажите
город, оставьте остальные REPLACE и заполните их после шага 5. Не публикуйте
заполненный шаблон в GitHub. Эти значения относятся к вашему приватному проекту.

```text
Используй Resale Ops для подготовки объявлений о продаже вещей.
В каждом новом чате перед работой прочитай skill и нужные справочные разделы:
https://raw.githubusercontent.com/mkayander/resale-ops/main/skills/resale-ops/SKILL.md
Относительные ссылки открывай в той же папке GitHub-репозитория.
Перед первым использованием проверь текущий commit ветки main и запиши его в
инструкции проекта как baseline источника. В следующих чатах сравнивай с ним.
Если источник или Google-сервисы недоступны, сообщи, чего не хватает.

Google Drive — фото и материалы объявлений. Google Sheets — очередь вещей.
Используй существующие папки и обновляй строку вещи по её ID.

Папка Resale: REPLACE
Подпапка queue: REPLACE
Таблица Google Sheets: REPLACE
Вкладка: Queue
Город: REPLACE
Площадки: Авито и Юла.

Уточни данные вещи, предложи быструю и обычную цену, подготовь текст и фото
по правилам skill. Сохрани материалы в Drive, обнови очередь и покажи ссылки.
Объявления размещаю я вручную. Отвечай на языке моего сообщения.
```

## 4. Проверьте чтение skill и доступ к облаку

Начните новый чат внутри проекта и скопируйте:

```text
Проверь настройку Resale Ops: прочитай skill, проверь доступ к Drive и Sheets.
Если ID заполнены, прочитай queue и заголовки Queue. Покажи результат проверки.
```

Проверьте ответ и ссылки. Если чтение GitHub не работает, перейдите к разделу
«Если ссылка на skill не открывается» ниже. Если нет записи Drive/Sheets,
сначала настройте подходящее подключение. Черновик в чате возможен и без него,
но облачная очередь ещё не будет настроена.

## 5. Создайте или переиспользуйте облачную очередь

Если очередь уже настроена и проверена, пропустите создание. Иначе отправьте:

```text
Настрой Resale Ops в моём Google Drive и Google Sheets.
Сначала проверь сохранённые ID и существующие Resale и таблицу очереди.
Если найдено несколько вариантов, уточни выбор. Если их ещё нет, создай приватную
папку Resale с подпапкой queue и отдельную таблицу Resale Queue с вкладкой Queue.
Не изменяй другие ресурсы. Заголовки Queue:
id, status, title, city, list_price_rub, quick_sale_rub, metadata_status,
post_photo_count, prepared_at, updated_at, folder_name, folder_url, notes.
При переиспользовании таблицы сохрани её строки, формулы и дополнительные столбцы.
Создай или обнови приватный файл .resale-locations.json внутри папки Resale в Drive
по схеме skill и проверь его чтением.
Покажи готовые строки для замены REPLACE в инструкциях проекта.
Город по умолчанию: [ваш город]. Площадки: Авито и Юла.
Проверь результат чтением и покажи ссылки на Resale, queue и таблицу.
Если нужной операции нет, сообщи об этом; не выдумывай ID и успешные записи.
```

Откройте ссылки, проверьте результат и замените REPLACE в блоке инструкций проекта.
Не храните реальные ID только в этом чате: новым чатам нужны инструкции проекта
или доступ к приватному файлу `.resale-locations.json` внутри папки `Resale` в Drive.

## 6. Загрузите фото и подготовьте первую вещь

Для первой вещи попросите:

```text
Создай в моей облачной очереди одну новую вещь: [краткое название].
Создай папку с уникальным ID, inbox, photos/post, listing.md и meta.json.
Добавь строку в Queue со статусом draft и ссылкой на папку вещи.
Покажи ссылку на inbox для загрузки фотографий.
```

В Google Drive на телефоне или ПК откройте `inbox` по ссылке и загрузите фото
**одной вещи**: общий вид, маркировку модели, комплект и дефекты. Проверьте,
что на снимках нет адресов, документов, лиц и других личных данных.

Теперь отправьте запрос, заменив поля в квадратных скобках:

```text
Используй resale-ops. Подготовь объявление для Авито и Юлы для вещи [ID или ссылка
на папку]. Фотографии уже в её inbox в Google Drive.

Город: [ваш город, без точного адреса]
Вещь и модель, если известны: [что продаёте]
Состояние и проверка работоспособности: [что проверено, что неизвестно]
Дефекты: [все известные дефекты]
Комплект: [что входит и чего нет]
Срок продажи: [быстро / готов подождать / конкретный срок]
Передача: [самовывоз / доставка / оба варианта]
Есть ли уже объявление этой вещи: [нет / есть на ... / не знаю]

Сначала задай важные уточняющие вопросы. Затем предложи цену для быстрой
продажи и обычную стартовую цену с источниками и оговорками. Подготовь заголовок,
описание, поля и порядок фото отдельно для каждой площадки.
Сохрани результат в listing.md и meta.json, обнови эту строку Queue по ID.
Подготовь очищенные от метаданных копии фото в photos/post, если инструменты
позволяют это реально выполнить и проверить. До этого не ставь статус ready.
Я проверю результат и опубликую вручную.
```

Агенту может понадобиться временное рабочее пространство для обработки фото.
Это не требует постоянной синхронизируемой папки на вашем ПК. Если обработка
или загрузка копий недоступна, агент должен сообщить об этом, оставить вещь
неготовой к размещению и дать ручной следующий шаг. Не передавайте в чат пароли,
коды входа, cookies или ключи сервисных аккаунтов.

## 7. Ответьте на уточнения и выберите цену

Агент должен отделить видимые факты от предположений, уточнить модель и состояние,
а затем предложить ценовые варианты. Это оценка по доступным **ценам предложений**,
а не обещание продажи за определённую сумму или срок.

Если веб-поиск недоступен, попросите поисковые запросы и проверьте похожие
объявления самостоятельно. Передайте ссылки, цены, состояние и время проверки.
Без источников не считайте оценку подтверждённой рынком.

Выберите стартовую цену и при необходимости попросите исправить текст.

## 8. Проверьте и разместите объявление

Перед переносом на площадку проверьте:

- точную модель, состояние, дефекты и комплект;
- выбранную цену, город и условия передачи;
- что все характеристики подтверждены вами или источниками;
- порядок фото, права на изображения и отсутствие личных данных;
- EXIF/GPS: удаление метаданных должно быть выполнено и проверено отдельно;
- что на этой площадке уже нет объявления или черновика той же вещи.

Откройте `listing.md` и очищенные копии в `photos/post` по ссылке из строки Queue.
Скопируйте текст и поля в форму Авито/Юлы, загрузите выбранные фото, проверьте
предпросмотр и опубликуйте самостоятельно. Resale Ops не входит в ваш аккаунт,
не заполняет формы и не публикует объявления. Успешный первый результат —
проверенный пакет текста, цены, полей и фото в Drive и актуальная строка Queue
для ручного размещения. После публикации сообщите агенту площадку и ссылку:
он обновит строку до `posted` как ваше подтверждение, а не как собственную публикацию.

## Если ссылка на skill не открывается

Более надёжная альтернатива — загрузить workflow в источники проекта. Нужен один
читаемый файл resale-ops-project-context.md со всем SKILL.md и references.
Попросите агента с доступом к репозиторию собрать его. Если собираете сами из
скачанного репозитория, команда (Python 3.10+, без дополнительных зависимостей):

```sh
python scripts/build_project_context.py --output /chosen/path/resale-ops-project-context.md
```

Загрузите результат в проект. В блоке инструкций замените абзац со ссылкой на:

```text
Перед работой в каждом новом чате прочитай файл resale-ops-project-context.md
из источников проекта и нужные справочные разделы внутри него.
```

Повторите проверку из шага 4 с загруженным файлом.

В режиме ссылки main читается текущая версия. Для фиксированной версии замените
main на выбранный commit SHA и используйте тот же SHA для references. В режиме
снимка обновляйте файл вручную, когда решите принять новую версию. Ни один режим
не гарантирует безошибочной работы: проверяйте реальные результаты операций.

## Установка в Codex, Claude Code или Cursor

Этот раздел нужен только для этих приложений; для ChatGPT Project он не требуется.
Откройте отдельную папку проекта, например My Resale, и терминал в ней.
Нужны [Node.js LTS](https://nodejs.org/en/download) и [Git](https://git-scm.com/downloads).
После их установки откройте терминал заново. Выполните одну команду:

| Приложение | Команда |
| --- | --- |
| Codex | `npx skills add mkayander/resale-ops --skill resale-ops --agent codex` |
| Claude Code | `npx skills add mkayander/resale-ops --skill resale-ops --agent claude-code` |
| Cursor | `npx skills add mkayander/resale-ops --skill resale-ops --agent cursor` |

Подтвердите скачивание пакета skills; если появится выбор области, выберите Project.
Дождитесь успешной установки и откройте новую сессию в той же папке.
Вызовите `$resale-ops` в Codex или `/resale-ops` в Claude Code/Cursor, либо напишите
«Используй resale-ops». Затем выполните общие шаги 2, 4–8 выше. Сохраните настройки
из шага 5 в правилах своего проекта. Подключения Google нужны отдельно.

Альтернатива для Claude Code — плагин из нашего GitHub-каталога сообщества:

```sh
claude plugin marketplace add mkayander/resale-ops
claude plugin install resale-ops@mkayander-plugins --scope project
```

После перезапуска сессии вызывайте `/resale-ops:resale-ops`. Выберите один способ
установки, не ставьте плагин и standalone skill одновременно. Это собственный
каталог Max Kayander, а не одобрение Anthropic или OpenAI.

## Если что-то не получилось

| Проблема | Действие |
| --- | --- |
| GitHub недоступен или прочитан только фрагмент | Загрузите полный workflow и явно переключите режим, как описано выше. |
| Drive доступен только для поиска | Подключите инструменты с чтением фото и записью файлов/строк; очередь пока не настроена. |
| В новом чате снова нужны ID | Заполните инструкции проекта и начните чат внутри того же проекта. |
| Агент не видит фото | Проверьте папку inbox, права подключения и поддержку изображений. |
| Нет обработки фото | Оставьте draft/researching; подготовьте и проверьте копии вручную перед ready. |
| Нет веб-поиска | Передайте проверенные аналоги со ссылками, ценами и временем проверки. |
| npx или git не найдены | Для локальной установки установите Node.js LTS/Git и перезапустите терминал. |
| Локально skill не найден | Откройте ту же папку и новую сессию; проверьте, что установлена вся папка с references. |

## Дополнительные возможности

Google Drive + Google Sheets — сценарий по умолчанию. Локальная синхронизация,
другие облака, Python-утилиты и CSV доступны по вашему выбору, но не нужны для
настройки основного сценария. Расширенные сведения: [облачная очередь](docs/DRIVE-SHEETS-QUEUE.md)
и [установка и обновления](docs/INSTALL.md).

Источники о возможностях ChatGPT: [проекты](https://learn.chatgpt.com/docs/projects)
и [Google Drive](https://help.openai.com/en/articles/10929079-google-drive-app-and-setup-in-chatgpt).
[Исходники и сообщения о проблемах](https://github.com/mkayander/resale-ops).
